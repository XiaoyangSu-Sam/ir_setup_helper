第一次使用 · 新手设置与故障检查
  1. 在运行 iRacing 的 Windows 电脑，从开始菜单打开 iRacing Registration Assistant，再点击“打开控制台”。本机使用无需 Tailscale。
  2. 正常打开并登录 iRacing。找不到客户端时，在助手小窗口点击“选择 iRacing 客户端”，选择 ui 文件夹里的 iRacingUI.exe。
  3. 先点下面“检查运行条件”。按未满足项目处理后重新检查；然后先做“只检查，不报名”测试。
  4. 手机或另一台电脑：两端安装 Tailscale 并登录自己的同一账号。展开下方“手机连接”，在主电脑检查并开启私人访问；另一设备用浏览器打开生成的 HTTPS 地址，输入主电脑显示的访问密钥。不要在手机使用 127.0.0.1。
  5. 主电脑开机、联网、不休眠，助手保持运行。关闭网页或锁屏可以；关机、注销、退出助手会停止任务。每位队友安装后使用自己的地址、密钥和 iRacing 登录。
